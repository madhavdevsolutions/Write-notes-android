# 📝 Write Notes – Android Notes App

## 📖 Overview
MyNotes is a simple and lightweight Android note-taking application built using **Java** and **Room Database**.  
It allows users to create, view, search, and manage notes efficiently with a clean and user-friendly interface.

---

## ✨ Features
- ➕ Add notes with title and content
- 🔍 Search notes by title or content
- 🗂 View notes in Grid or List layout
- 🔄 Switch layouts dynamically
- 💾 Offline storage using Room Database
- 🎨 Custom dialog for adding notes
- 📱 Responsive UI with ViewBinding

---

## 🛠 Tech Stack
- **Language:** Java
- **Database:** Room (SQLite)
- **UI Components:** RecyclerView, Dialog, SearchView
- **Architecture:** Room Persistence Library
- **Binding:** ViewBinding
